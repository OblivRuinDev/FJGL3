## FJGL - Fork of Lightweight Java Game Library 3

FJGL is a fork of LWJGL (https://www.lwjgl.org), but unlike LWJGL,
it only supports on JDK25, and require access to `jdk.internal.*`.
Benifit to access to internal JDK, it can get better preformace.
